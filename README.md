# 特斯拉技术支持学习台

一个面向车辆技术支持岗位的交互式学习项目。项目把 CAN/LIN、UDS、整车低压电气、高压系统、域控制器和故障诊断思路做成可直接操作的网页演示，重点训练“故障现象 → 数据证据 → 系统分层 → 根因判断”的诊断视角。

## 项目亮点

- **Model 3 车辆主视觉**：首页提供 3D 模型与 2D 技术参考图选项卡，3D 模型支持旋转和缩放，适合从车辆外观进入系统学习。
- **Tesla 服务工作流**：按客户现象演示维护模式、网关检查、DTC/实时数据、Toolbox 定向测试、最小必要动作和修复验证。
- **CAN 总线实验室**：用波形和硬件动画解释 CAN-H/CAN-L 差分电平、显性 0/隐性 1、线与逻辑和 120Ω 终端电阻。
- **逐比特仲裁**：两个节点同时发送 ID，按最高位开始比较，低优先级节点检测到“发送 1、读到 0”后退让。
- **CAN-ID 与报文结构**：对照二进制、十六进制、十进制，展示标准帧/扩展帧、IDE 位、生产者-消费者模型和整车 CAN 矩阵。
- **UDS 诊断**：区分 CAN 底层和 UDS 应用层，演示 `0x10`、`0x22`、`0x19`、`0x27` 以及 `0x34/36/37` 刷写流程。
- **整车域网络**：展示动力、底盘、车身、娱乐四条独立 CAN 网段、网关转发和故障隔离，以及域控制器和以太网骨干的关系。
- **低压电气架构**：展示低压电池、DC-DC、保险丝、继电器、ECU、传感器、执行器、唤醒线、搭铁和高压主接触器的连接逻辑。
- **低压测量实验**：切换传统 12V/新型低压锂电架构，注入电池低压、保险丝开路、搭铁压降和唤醒丢失，并在五个测点读取电压。
- **纯电高压拓扑**：展示电池包、BMS、接触器、逆变器、驱动电机、OBC、DC-DC、充电接口和 HVIL。
- **故障诊断案例库**：覆盖低压供电、接地、CAN 终端、总线短路、节点掉线、DTC、热管理、制动、车门和软件刷写等典型问题。

## 推荐演示路径

1. 从“学习总览”切换 Model 3 的 2D/3D 主视觉，说明车辆系统学习入口和项目边界。
2. 进入“车载网络”，先展示四域 CAN 网络与网关转发。
3. 打开“CAN 实验室”，用自动播放或单步操作演示差分电平、终端电阻和位仲裁。
4. 在 CAN-ID/报文面板说明 ID 是消息编号而不是 ECU 地址，再切换到 UDS 帧说明应用层服务码。
5. 进入“低压电路”，注入保险丝开路或搭铁压降，使用 P1-P5 测点定位根因。
6. 在“软件与刷写”按现象推进维护模式和 Toolbox 工作流，区分定向重装、整车更新与用户数据恢复。
7. 最后用“故障诊断”案例演示从现象、DTC、数据流到根因的判断过程。

## 核心技术要点

### CAN 与 LIN

CAN 是多 ECU 共享的差分总线，显性位 0 可以覆盖隐性位 1，因此仲裁不会破坏高优先级报文。CAN 网络两端通常使用 120Ω 终端电阻，两个终端并联测得约 60Ω。LIN 是单线主从网络，常用于车窗、雨刮、门锁等成本敏感的附属部件。

### UDS

CAN-ID 是报文的“信封地址”，UDS 服务码是信封内的业务数据。常见服务包括：`0x10` 切换会话、`0x22` 读取 DID、`0x19` 读取 DTC、`0x27` 安全访问、`0x34` 请求下载、`0x36` 传输数据、`0x37` 结束传输。

### 低压诊断思路

车辆模块不工作时，优先验证：

1. 保险丝和模块供电是否存在；
2. 搭铁点和回路压降是否正常；
3. 唤醒信号和连接器是否可靠；
4. CAN/LIN 报文是否存在、是否有错误帧；
5. 最后再判断 ECU 硬件或软件逻辑。

## 本地运行

项目是无构建步骤的静态网站。使用任意静态 HTTP 服务即可，例如：

```powershell
python -m http.server 8765
```

然后访问 `http://127.0.0.1:8765/index.html`。同一局域网设备可访问主机局域网 IP 加端口，例如 `http://<局域网IP>:8765/index.html`。

## 本地 3D 模型

主页从 `assets/models/tesla.glb` 加载本地 glTF Binary 模型，Three.js、GLTFLoader 和 OrbitControls 均保存在 `assets/vendor/three/`，不依赖 Sketchfab 在线播放器。模型加载后默认显示 3D 视图，可切换到 2D 参考图；浏览器需要启用 WebGL。模型来源为 [Tesla 2018 Model 3](https://sketchfab.com/3d-models/tesla-2018-model-3-5ef9b845aaf44203b6d04e2c677e444f)，作者 Ameer Studio，授权为 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。

## 项目边界

这是用于学习和面试展示的教学模拟器，不连接真实车辆，也不替代维修手册、诊断仪或高压作业安全规范。页面中的报文、波形和故障数据均为简化教学模型。
